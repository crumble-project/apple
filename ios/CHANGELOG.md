# Changelog

## Unreleased

- Add provider account sign-in to Settings, such as ChatGPT, Codex, or Claude. **Providers** shows what is saved and offers each provider's sign-ins next to its API key, with **Sign Out** for an account. **Open Sign-In Page** and device-code links open in the system sign-in sheet, which closes when the server finishes; **Open in Safari** and **Copy Link** are for a browser with an address bar. The app answers the provider's questions, shows success only once the server saved the sign-in, picks up a sign-in running on the server, and **Cancel Sign-In** ends it. A blank answer is allowed for text questions, so GitHub Copilot can use github.com.
- Add coding jobs and desktop job cards. A job a bot starts shows as a card in the chat that opens its task, replies, and tool steps, with its model and spend, **Download Transcript**, and earlier activity. Tap a step for its output. A desktop job's panel opens the bot desktop. Job reports stay behind their card, as on the web.
- Answer a coding job's question in the chat or on the job's panel: pick an option or write an answer. An answer that fails keeps what you wrote.
- The bot editor gains the **Coding** toggle, shown when the server can run coding jobs.
- Add group chats. The sidebar lists them under **Group Chats**; create one with **New Group Chat** from two to six bots, edit it from its toolbar or row, and delete it from its row or the editor after a confirmation. A group shows each bot's messages with its name and avatar, source links for pages it read, reactions beside the message they answer, which bots are answering or disabled, failed turns, and when the bots are paused waiting for you. Messages appear at once and reconcile with the server; failed ones keep their draft and offer **Retry**. `@` completes the group's members, replies and attachments work as in a bot chat, the stop button ends every bot's turn in the group, and the chat catches up when you return from the background. Group answers notify as "Ada in Trip" unless the group is on screen, and a tapped notification opens the group.
- Add the bot desktop. **Bot Desktop** in the chat toolbar opens it over the whole screen, with **Take Control** and **Hand Back**, **Reconnect**, and the reason when the server can't show it, such as a server without a desktop image. Control changes only when the server confirms; leaving the bot desktop or sending the app to the background hands control back, within the time iOS allows and while the server is reachable, and returning reconnects the viewer. With control, touch is the mouse: tap to click, drag to select, touch and hold to right-click, and drag with two fingers to scroll. **Keyboard** opens a field that sends its text to the bot desktop, plus Esc, Tab, arrow, Return, and Delete keys.
- The bot profile shows a live, watch-only preview of a bot's desktop that opens the full one, or **Sleeping** with tap to wake. A desktop job's notification opens the bot desktop.
- The bot editor gains the **Bot desktop** toggle, shown when the server has a desktop image, with an optional desktop job model. Saving a bot in the iOS editor used to remove its `desktop` and `coding` tools and any other tool without a toggle; it now keeps them.
- Bots show the avatar stored on the server, rendered with Open Bot Avatar, instead of a face seeded from their ID: `.thinking` while working and dimmed and still while paused. The bot editor gains the web app's avatar editor: body and eye colors, a gallery of 22 shapes, **Import** of a definition's JSON, and **Generate**, which copies a design prompt. The choice saves when you create or update a bot.
- Sign in with account email and password in Settings; the app stores the returned session.
- Build against bot contract 6.0.0. The bearer token must be an account session token from `POST /api/auth/sign-in/email`; the old server token is rejected.
- CI runs SwiftLint in its own job, beside the build.
- New bots start with **Schedule tasks**, **Message other bots**, and **Code mode** on, besides **Memory**, and may message every existing bot.
- Move into the `crumble-project/apple` repository and reference `../apfelkern` as a local package instead of a pinned revision. This adopts apfelkern through bot contract 1.6.0.
- CI only builds the app and its tests with cached Swift packages and build products; tests need a simulator and run locally. `scripts/build.sh` runs the CI build, and `scripts/test.sh` accepts `unit`, `ui`, or `all`.
- Replace the local glossary with a link to the canonical glossary in the spec repository.
- Remove references to the obsolete agent folder field, as required by the current shared package and server contract.
- Adopt apfelkern's generated API operations, shared activity and push models, and event decoding without an app-local generator.
- Pin apfelkern by commit over HTTPS and run unsigned simulator tests in public-repository CI.
